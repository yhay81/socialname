# Security policy

## Supported code

Security fixes target the current `main` branch and, when practical, the most
recent published release. The legacy Python package is not an actively
supported product surface, but reports that affect current users or migration
remain welcome.

## Report a vulnerability privately

Do not open a public issue or pull request for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/yhay81/socialname/security/advisories/new).

Include only what is needed to reproduce and assess the problem:

- affected component, version, or commit;
- expected and observed security boundary;
- minimal reproduction steps;
- realistic impact; and
- a proposed mitigation, if you have one.

Remove usernames, search targets, API keys, database URLs, cookies, tokens,
complete response bodies, and unrelated personal data. Do not test against
accounts or systems you do not own or have permission to assess.

The maintainers will coordinate disclosure and remediation through the private
advisory. Please allow time for validation before publishing details.
